# Retro Jenga: ¡Que no caiga la torre!

Tablero virtual para retrospectivas de equipo (15 personas, 60 min). Un solo archivo HTML, sin dependencias.

- Dado que decide el tipo de bloque (funcionó / tambalea / idea / comodín)
- Temporizador por turno y reloj de sesión de 60 min
- Torre con equilibrio tipo Jenga: las 3 filas de abajo y la de arriba están fijas, y la torre cae si queda muy desequilibrada
- Votación con puntos a ciegas para elegir las acciones del próximo Sprint

Abre `index.html` en el navegador y comparte pantalla.
